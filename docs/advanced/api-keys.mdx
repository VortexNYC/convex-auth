# API keys

`convex-auth` has a native `authApiKeys` table and a set of helpers for creating, hashing, verifying, and rotating API keys. The `convex-auth-react` package gives you controlled forms and lists; the `convex-auth` package gives you the low-level `machine` helpers.

## Mount the API keys component

If you need service/API-key authentication, mount the `apiKeys` component alongside the core component:

```ts convex/convex.config.ts
import { defineApp } from "convex/server";
import { v } from "convex/values";
import authCore from "convex-auth/convex.config/core";
import authApiKeys from "convex-auth/convex.config/apiKeys";

const app = defineApp({
  env: {
    JWT_PRIVATE_KEY: v.string(),
    JWKS: v.string(),
  },
});

app.use(authCore, {
  env: {
    JWT_PRIVATE_KEY: app.env.JWT_PRIVATE_KEY,
    JWKS: app.env.JWKS,
  },
});

app.use(authApiKeys, {
  env: {
    JWT_PRIVATE_KEY: app.env.JWT_PRIVATE_KEY,
    JWKS: app.env.JWKS,
  },
});

export default app;
```

## Create an API key

```tsx src/ApiKeys.tsx
import { useState } from "react";
import { useMutation } from "convex/react";
import { ConvexApiKeyCreateForm } from "convex-auth/react";
import { api } from "../convex/_generated/api";

const SCOPES = ["read:users", "write:users"] as const;

export function CreateApiKey() {
  const create = useMutation(api.apiKeys.create);
  const [creating, setCreating] = useState(false);
  const [state, setState] = useState({
    name: "",
    scopes: [],
    ipAllowlist: "",
    expiresInDays: "30",
  });

  return (
    <ConvexApiKeyCreateForm
      apiEnabled
      scopeOptions={SCOPES}
      state={state}
      creating={creating}
      onNameChange={(name) => setState((s) => ({ ...s, name }))}
      onScopesChange={(scopes) => setState((s) => ({ ...s, scopes }))}
      onIpAllowlistChange={(ipAllowlist) => setState((s) => ({ ...s, ipAllowlist }))}
      onExpiresInDaysChange={(expiresInDays) => setState((s) => ({ ...s, expiresInDays }))}
      onSubmit={async () => {
        setCreating(true);
        try {
          await create({
            name: state.name,
            scopes: state.scopes,
            allowedIpRanges: state.ipAllowlist
              .split(/\n|,/)
              .map((s) => s.trim())
              .filter(Boolean),
            expiresInDays: state.expiresInDays === "none" ? null : Number(state.expiresInDays),
          });
        } finally {
          setCreating(false);
        }
      }}
    />
  );
}
```

## List and revoke

```tsx
import { useMutation, useQuery } from "convex/react";
import { ConvexApiKeyList } from "convex-auth/react";
import { api } from "../convex/_generated/api";

export function ApiKeySettings() {
  const keys = useQuery(api.apiKeys.list) ?? [];
  const revoke = useMutation(api.apiKeys.revoke);
  const rotate = useMutation(api.apiKeys.rotate);

  return (
    <ConvexApiKeyList
      apiKeys={keys}
      copy={{
        emptyMessage: "No API keys yet.",
      }}
      onRevoke={async (id) => revoke({ id })}
      onRotate={async (id) => rotate({ id })}
    />
  );
}
```

## Server-side helpers

`convex-auth/convex` re-exports the `machine` helpers you need to build `apiKeys.create`, `apiKeys.list`, `apiKeys.revoke`, and `apiKeys.rotate` in your own Convex actions:

- `normalizeConvexApiKeyCreateInput` — turn a user payload into a validated create shape.
- `createConvexApiKeyCreateArgsValidator` — build the validator for your mutation.
- `deriveApiKeySecret` / `hashApiKeySecret` / `verifyApiKeySecret` — generate and verify the secret token.
- `requireActiveApiKeyRecord` — resolve an API key from a secret in a request.
- `resolveApiKeyRecordStatus` — check active, expired, revoked, or disabled status.

These run inside Convex actions because they need `crypto.subtle` and other non-deterministic work. The component's `authApiKeys` table stores only the hash, prefix, scopes, and metadata.
