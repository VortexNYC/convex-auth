### `ConvexAuthIdentityProvisioner`

<Component path="convex-auth-identity-provisioner" />

Lower-level provisioner — `ConvexAuthConvexIdentityProvisioner` wraps this with the Convex function references already bound.

**Props**

| Name                   | Type                     | Optional | Description                                              |
| ---------------------- | ------------------------ | -------- | -------------------------------------------------------- |
| `auth`                 | `ConvexAuthState`        | No       | Current auth state to provision against.                 |
| `currentUser`          | `unknown`                | No       | The resolved user — `null` until provisioning completes. |
| `sessionSubject`       | `string \| null`         | No       | Session subject being provisioned.                       |
| `provisionCurrentUser` | `() => Promise<unknown>` | No       | Callback that provisions the user when invoked.          |
