### `PasskeyManager`

<Preview path="passkey-manager" of="PasskeyManager" />

Manages WebAuthn passkeys for the signed-in user: lists registered passkeys, registers a new one, and supports rename and revoke. Registration and authentication callbacks receive/return the WebAuthn JSON types, so wire them to your passkey endpoints.

See [Passkeys](/passkeys) for the full feature walkthrough.
