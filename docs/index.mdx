title: Convex Auth
description: Convex-native auth for production apps.
---

Convex-native auth for production apps. Users, sessions, identities, organizations, API keys, webhooks, and MCP auth live in your Convex database. No external auth service required.

If you are new here, follow this order:

  <Step title="Read the story" href="./how-we-got-here">
    Why `convex-auth` exists and how we got here.
  </Step>
  <Step title="Understand the concepts" href="./concepts">
    The five building blocks: component, config, actions, HTTP routes, and React client.
  </Step>
  <Step title="Install" href="./installation">
    Add the packages, generate signing keys, and set environment variables.
  </Step>
  <Step title="Quickstart" href="./quickstart">
    Wire `convex/auth.ts`, mount the component, set up the React client, and sign up a user.
  </Step>
</Steps>
