`convexAuth` is configured in `convex/auth.ts`. The object it returns is re-exported so Convex can see the actions, queries, and HTTP routes.

## Top-level shape

```ts
import { components } from "./_generated/api";
import { convexAuth } from "@vortex-api/convex-auth/convex";

export const auth = convexAuth({
  component: components.convexAuth,
  emailAndPassword: {/* ... */},
  oauth: {/* ... */},
  magicLink: {/* ... */},
  emailOtp: {/* ... */},
  captcha: {/* ... */},
});

export const { signUp, signIn, signOut, addHttpRoutes } = auth;
```

| Option             | Type                                  | Required | Description                                                |
| ------------------ | ------------------------------------- | -------- | ---------------------------------------------------------- |
| `component`        | `ConvexAuthComponentHandle`           | Yes      | Component handle from `components.convexAuth`.             |
| `components`       | `{ core: ConvexAuthComponentHandle }` | No       | Same as `component`; use one or the other.                 |
| `emailAndPassword` | `NativeEmailAndPasswordConfig`        | No       | Email/password sign-up, sign-in, verification, and reset.  |
| `username`         | `NativeUsernameConfig`                | No       | Username/password sign-up and sign-in.                     |
| `oauth`            | `NativeOAuthConfig`                   | No       | Google, GitHub, and Discord OAuth.                         |
| `magicLink`        | `NativeMagicLinkConfig`               | No       | Magic-link sign-in via email.                              |
| `emailOtp`         | `NativeEmailOtpConfig`                | No       | Email-based one-time passcodes.                            |
| `phone`            | `NativePhoneConfig`                   | No       | SMS one-time passcodes for phone sign-in and verification. |
| `oneTap`           | `boolean \| NativeOneTapConfig`       | No       | Google One Tap sign-in via ID-token verification.          |
| `captcha`          | `CaptchaConfig`                       | No       | CAPTCHA gating for sign-up and password reset endpoints.   |

## `emailAndPassword`

| Option                          | Type                        | Default   | Description                                                             |
| ------------------------------- | --------------------------- | --------- | ----------------------------------------------------------------------- |
| `enabled`                       | `boolean`                   | `true`    | Enable email/password sign-up and sign-in.                              |
| `disableSignUp`                 | `boolean`                   | `false`   | Disable new sign-ups. Existing users can still sign in.                 |
| `autoSignIn`                    | `boolean`                   | `true`    | Automatically sign the user in after successful sign-up.                |
| `requireVerifiedEmail`          | `boolean`                   | `false`   | Reject sign-in for users whose email is not verified.                   |
| `minPasswordLength`             | `number`                    | `8`       | Minimum password length.                                                |
| `maxPasswordLength`             | `number`                    | `256`     | Maximum password length.                                                |
| `checkBreach`                   | `boolean`                   | `true`    | Check new passwords against Have I Been Pwned and reject breached ones. |
| `sessionTtlMs`                  | `number`                    | `7 days`  | Access-token/session lifetime in milliseconds.                          |
| `refreshTokenTtlMs`             | `number`                    | `30 days` | Refresh-token lifetime in milliseconds.                                 |
| `verificationCodeTtlMs`         | `number`                    | `1 hour`  | Email-verification code lifetime.                                       |
| `passwordResetCodeTtlMs`        | `number`                    | `1 hour`  | Password-reset code lifetime.                                           |
| `trustedOrigins`                | `string[]`                  | `[]`      | Origins allowed for `callbackURL` in verify/reset routes.               |
| `revokeSessionsOnPasswordReset` | `boolean`                   | `true`    | Revoke all sessions after a successful password reset.                  |
| `rateLimit`                     | `{ windowMs, maxAttempts }` | —         | Rate limiting for sign-in attempts per email.                           |
| `email`                         | `EmailConfig`               | Required  | Email sender and path configuration.                                    |
| `onExistingUserSignUp`          | `(data) => Promise<void>`   | —         | Callback when an existing user tries to sign up.                        |
| `onPasswordReset`               | `(data) => Promise<void>`   | —         | Callback after a successful password reset.                             |

### `email`

| Option         | Type                         | Required | Description                                                 |
| -------------- | ---------------------------- | -------- | ----------------------------------------------------------- |
| `from`         | `string`                     | Yes      | `From:` address for all auth emails.                        |
| `appOrigin`    | `string`                     | No       | Origin used for email links. Defaults to `CONVEX_SITE_URL`. |
| `verifyPath`   | `string`                     | No       | In-app path for the verify-email redirect.                  |
| `resetPath`    | `string`                     | No       | In-app path for the reset-password redirect.                |
| `sendEmail`    | `(draft) => Promise<string>` | Yes      | Send the email. Return a message/queue id.                  |
| `sendOnSignUp` | `boolean`                    | No       | Send a verification email on sign-up.                       |
| `sendOnSignIn` | `boolean`                    | No       | Send a verification email on sign-in for unverified users.  |

## `username`

| Option                 | Type                                                | Default   | Description                                                    |
| ---------------------- | --------------------------------------------------- | --------- | -------------------------------------------------------------- |
| `enabled`              | `boolean`                                           | `true`    | Enable username/password sign-up and sign-in.                  |
| `disableSignUp`        | `boolean`                                           | `false`   | Disable new sign-ups. Existing users can still sign in.        |
| `autoSignIn`           | `boolean`                                           | `true`    | Automatically sign the user in after successful sign-up.       |
| `minUsernameLength`    | `number`                                            | `3`       | Minimum normalized username length.                            |
| `maxUsernameLength`    | `number`                                            | `32`      | Maximum normalized username length.                            |
| `usernameValidator`    | `(username: string) => boolean \| Promise<boolean>` | —         | Extra validation on the normalized username (`false` rejects). |
| `minPasswordLength`    | `number`                                            | `8`       | Minimum password length.                                       |
| `maxPasswordLength`    | `number`                                            | `128`     | Maximum password length.                                       |
| `checkBreach`          | `boolean`                                           | `true`    | Check new passwords against Have I Been Pwned.                 |
| `requireVerifiedEmail` | `boolean`                                           | `false`   | Reject sign-in when an attached email is unverified.           |
| `sessionTtlMs`         | `number`                                            | `7 days`  | Access-token/session lifetime.                                 |
| `refreshTokenTtlMs`    | `number`                                            | `30 days` | Refresh-token lifetime.                                        |
| `rateLimit`            | `{ windowMs, maxAttempts }`                         | —         | Rate limiting for sign-in attempts per username.               |
| `captcha`              | `CaptchaConfig`                                     | —         | CAPTCHA gating for username sign-up.                           |
| `onExistingUserSignUp` | `(data) => Promise<void>`                           | —         | Callback when a taken username or email is re-registered.      |

Usernames are normalized (trimmed, lowercased) before storage and lookup, and must match `^[a-z0-9._-]+$` after normalization. `displayUsername` preserves the caller-supplied casing.

## `oauth`

| Option             | Type                    | Default | Description                                                                                                                             |
| ------------------ | ----------------------- | ------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `github`           | `GitHubProviderConfig`  | No      | GitHub OAuth app credentials.                                                                                                           |
| `google`           | `GoogleProviderConfig`  | No      | Google OAuth app credentials.                                                                                                           |
| `discord`          | `DiscordProviderConfig` | No      | Discord OAuth app credentials.                                                                                                          |
| `redirectURI`      | `string`                | No      | Full callback URL registered with the OAuth provider.                                                                                   |
| `trustedOrigins`   | `string[]`              | No      | Origins allowed for `callbackURL`, `errorURL`, and `newUserURL`.                                                                        |
| `sessionTtlMs`     | `number`                | 7 days  | OAuth session lifetime.                                                                                                                 |
| `trustedProviders` | `string[]`              | No      | Providers whose `emailVerified` claim is trusted for account linking — the only way implicit linking proceeds with an unverified email. |
| `accountLinking`   | `AccountLinkingConfig`  | No      | Policy for linking OAuth accounts to existing users.                                                                                    |

### Provider configs

Each OAuth provider takes:

```ts
{
  clientId: string;
  clientSecret: string;
}
```

Set the corresponding `*_CLIENT_ID` and `*_CLIENT_SECRET` environment variables.

### `accountLinking`

| Option                      | Type      | Default | Description                                                                                                                                                                                                                         |
| --------------------------- | --------- | ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `enabled`                   | `boolean` | `true`  | Allow linking OAuth accounts to existing users.                                                                                                                                                                                     |
| `disableImplicitLinking`    | `boolean` | `false` | Require explicit `linkSocial` to attach an OAuth account.                                                                                                                                                                           |
| `requiresEmailVerification` | `boolean` | `false` | Require the provider to report the email as verified before implicit linking. Effectively required regardless for providers not in `trustedProviders` — the component refuses to link an unverified email into an existing account. |

## `magicLink`

| Option              | Type                        | Default | Description                                     |
| ------------------- | --------------------------- | ------- | ----------------------------------------------- |
| `enabled`           | `boolean`                   | `true`  | Enable magic-link sign-in.                      |
| `disableSignUp`     | `boolean`                   | `false` | Prevent magic links from creating new accounts. |
| `appOrigin`         | `string`                    | No      | Origin used in the magic link.                  |
| `expiresInMs`       | `number`                    | 5 min   | Token lifetime.                                 |

| `refreshTokenTtlMs` | `number`                    | 30 days | Refresh-token lifetime.                         |

## `emailOtp`

| Option                | Type                        | Default | Description                                      |
| --------------------- | --------------------------- | ------- | ------------------------------------------------ |
| `enabled`             | `boolean`                   | `true`  | Enable email OTP.                                |
| `disableSignUp`       | `boolean`                   | `false` | Prevent OTP from creating new accounts.          |
| `expiresInMs`         | `number`                    | 5 min   | OTP lifetime.                                    |
| `sessionTtlMs`        | `number`                    | 7 days  | Session lifetime after verification.             |

| `sendVerificationOTP` | `(data) => Promise<string>` | Yes     | Send the OTP email.                              |

## `phone`

| Option              | Type                                   | Default | Description                                                      |
| ------------------- | -------------------------------------- | ------- | ---------------------------------------------------------------- |
| `enabled`           | `boolean`                              | `true`  | Enable phone OTP.                                                |
| `disableSignUp`     | `boolean`                              | `false` | Prevent OTP sign-in from creating new accounts.                  |
| `expiresInMs`       | `number`                               | 5 min   | OTP lifetime.                                                    |
| `sessionTtlMs`      | `number`                               | 7 days  | Session lifetime after verification.                             |
| `refreshTokenTtlMs` | `number`                               | 30 days | Refresh-token lifetime.                                          |
| `rateLimit`         | `{ windowMs, maxAttempts }` \| `false` | 5/60s   | Per-phone rate limiting on sends and verifies. `false` disables. |
| `sendPhoneOtp`      | `(data) => Promise<string>`            | Yes     | Send the OTP SMS — e.g. `createTwilioSmsOtpSender`.              |

## `oneTap`

| Option                     | Type                                   | Default        | Description                                                         |
| -------------------------- | -------------------------------------- | -------------- | ------------------------------------------------------------------- |
| `enabled`                  | `boolean`                              | `true`         | Enable Google One Tap sign-in.                                      |
| `clientId`                 | `string`                               | `oauth.google` | Google OAuth client ID — the `aud` check. Required when standalone. |
| `hd`                       | `string`                               | `oauth.google` | Restrict to a Workspace hosted domain.                              |
| `maxTokenAge`              | `number`                               | `oauth.google` | Max ID-token age in seconds.                                        |
| `disableSignUp`            | `boolean`                              | `oauth.google` | Block new-user creation.                                            |
| `disableImplicitSignUp`    | `boolean`                              | `oauth.google` | Only allow accounts created by an explicit sign-up.                 |
| `requireEmailVerification` | `boolean`                              | `oauth.google` | Require `email_verified` from Google.                               |
| `sessionTtlMs`             | `number`                               | 7 days         | Session lifetime after sign-in.                                     |
| `refreshTokenTtlMs`        | `number`                               | 30 days        | Refresh-token lifetime.                                             |
| `rateLimit`                | `{ windowMs, maxAttempts }` \| `false` | 5/60s          | Token-hash + subject attempt limiting. `false` disables.            |

`oneTap: true` inherits `clientId`/`hd`/`maxTokenAge`/`fetchImpl` and the sign-up/verification lockdowns from `oauth.google`, plus `accountLinking`/`trustedProviders` from `oauth`. See [One Tap](./one-tap) for linking semantics.

## `captcha`

| Option      | Type                                                                         | Required | Description                                      |
| ----------- | ---------------------------------------------------------------------------- | -------- | ------------------------------------------------ |
| `provider`  | `"cloudflare-turnstile" \| "google-recaptcha" \| "hcaptcha" \| "captchafox"` | Yes      | CAPTCHA provider.                                |
| `secretKey` | `string`                                                                     | Yes      | Server-side verification secret.                 |
| `endpoints` | `string[]`                                                                   | No       | Paths to protect. Defaults to sign-up and reset. |

## Environment variables

| Variable                | Required | Purpose                                       |
| ----------------------- | -------- | --------------------------------------------- |
| `JWT_PRIVATE_KEY`       | Yes      | RS256 private key as exported JWK JSON.       |
| `JWKS`                  | Yes      | JWKS JSON containing the matching public key. |
| `CONVEX_SITE_URL`       | Yes      | Public `.convex.site` URL of your deployment. |
| `EMAIL_FROM_ADDRESS`    | Yes      | Default `From:` address for auth emails.      |
| `GITHUB_CLIENT_ID`      | No       | GitHub OAuth client ID.                       |
| `GITHUB_CLIENT_SECRET`  | No       | GitHub OAuth client secret.                   |
| `GOOGLE_CLIENT_ID`      | No       | Google OAuth client ID.                       |
| `GOOGLE_CLIENT_SECRET`  | No       | Google OAuth client secret.                   |
| `DISCORD_CLIENT_ID`     | No       | Discord OAuth client ID.                      |
| `DISCORD_CLIENT_SECRET` | No       | Discord OAuth client secret.                  |
