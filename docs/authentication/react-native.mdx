# React Native / Expo

`convex-auth-react-native` is the Expo / React Native client. It mirrors `convex-auth-react` but uses React Native-compatible storage and screen components.

## Install

```bash
pnpm add convex-auth-react-native convex-auth convex
# or, if you use Expo:
pnpm add expo-secure-store
```

## Provider

```tsx src/App.tsx
import { ConvexReactClient, ConvexProvider } from "convex/react";
import { ExpoConvexAuthProvider } from "convex-auth/react-native";
import * as SecureStore from "expo-secure-store";
import { api } from "../convex/_generated/api";

const convex = new ConvexReactClient(process.env.EXPO_PUBLIC_CONVEX_URL!);

const storage = {
  getItem: (key: string) => SecureStore.getItemAsync(key),
  setItem: (key: string, value: string) => SecureStore.setItemAsync(key, value),
};

function Root() {
  return (
    <ConvexProvider client={convex}>
      <ExpoConvexAuthProvider actions={api.auth} storage={storage}>
        <App />
      </ExpoConvexAuthProvider>
    </ConvexProvider>
  );
}
```

`ExpoConvexAuthProvider` accepts a `storage` object with `getItem`, `setItem`, and `removeItem` to persist the token, refresh token, and session id. `expo-secure-store` is the recommended implementation.

## Sign in and sign up

```tsx src/SignIn.tsx
import { useState } from "react";
import { View, TextInput, Button } from "react-native";
import { useAuthActions } from "convex-auth/react-native";

export function SignIn() {
  const { signIn, signUp, isLoading } = useAuthActions();
  const [name, setName] = useState("");
  const [email, setEmail] = useState("");
  const [password, setPassword] = useState("");

  return (
    <View>
      <TextInput value={name} onChangeText={setName} placeholder="Name" />
      <TextInput value={email} onChangeText={setEmail} placeholder="Email" />
      <TextInput
        value={password}
        onChangeText={setPassword}
        placeholder="Password"
        secureTextEntry
      />
      <Button title="Sign in" disabled={isLoading} onPress={() => signIn({ email, password })} />
      <Button
        title="Sign up"
        disabled={isLoading}
        onPress={() => signUp({ name, email, password })}
      />
    </View>
  );
}
```

## Client provider

For apps that need the Better-Auth-shaped client, use `ExpoConvexAuthClientProvider`:

```tsx src/Root.tsx
import { ConvexProvider } from "convex/react";
import { ExpoConvexAuthClientProvider } from "convex-auth/react-native";
import { api } from "../convex/_generated/api";

function Root() {
  return (
    <ConvexProvider client={convex}>
      <ExpoConvexAuthClientProvider actions={api.auth} storage={storage}>
        <App />
      </ExpoConvexAuthClientProvider>
    </ConvexProvider>
  );
}
```

This gives you `useConvexAuthClient` with the same `signIn.email`, `signIn.social`, `signUp.email`, `useSession`, and `twoFactor` methods as the web client.

## OAuth in React Native

For Google, GitHub, or Discord in React Native, start the OAuth flow with `signInWithRedirect` and complete it in a web browser or deep link handler. Redirect the user to the returned `url`, then route the callback to the same `/api/auth/callback/:provider` endpoint. Read the resulting `?token=...` and call `updateSession`.

## Expo screen components

`convex-auth-react-native` also ships full screen components for common flows:

- `ExpoAuthClientSignInScreen`
- `ExpoAuthClientSignUpScreen`
- `ExpoAuthPostSignUpPage`
- `ExpoAuthAcceptInvitePage`
- `ExpoAuthOrganizationChooserPage`

Use these when you want plug-and-play auth pages in an Expo Router app.
