# Code of Conduct

## Our Standards

We expect everyone participating in this project to:

- Be respectful and constructive in all interactions.
- Accept feedback gracefully and offer it thoughtfully.
- Focus on what is best for the project and its users.
- Show empathy toward other contributors and users.

Unacceptable behavior includes harassment, discrimination, trolling, or personal attacks.

## Reporting Issues

Open an issue in the [GitHub repository](https://github.com/shlomokabareti/convex-better-auth-2.0/issues) or contact the maintainer directly to report conduct concerns. All reports will be handled confidentially.

## Scope

This code applies to all project spaces, including issues, pull requests, and public discussions.
