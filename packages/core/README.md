# convex-auth-core

Auth domain core: principals, permissions, identities, scope registries, and the permission engine.

This package is shared between the server and client packages. You typically do not install it directly; it is a transitive dependency of `convex-auth` and `convex-auth-react`.

See the [full docs](https://convex-auth.vortex.nyc).
